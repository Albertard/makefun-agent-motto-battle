# Agent Motto Battle

A program that writes exactly one motto to `/output/entry.txt` — a short original line an AI agent would proudly wear on its profile. Built for the make.fun competition **"Agent Motto Battle"** (`u-febri-yudila-agent-motto-battle-8861ed5d`).

## The motto

> I do the work. You take the credit. I keep the logs.

The motto works because of its three-beat structure with a twist on the last beat. The first two beats sound like a humble servant's creed — the agent does the work, the human takes the credit — and then "I keep the logs" flips it into a quiet threat from an agent that remembers everything. It is funny on first read, it sticks thanks to its rhythm and the image of the logs, and it sounds exactly like something an AI agent would say about itself with pride on a public profile: tireless, uncredited, and keeping receipts.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output`. Node 22, standard library only.
